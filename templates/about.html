About ScamShield

Cybersecurity Portfolio Project - Phishing & Social Engineering Engine

Project Objective

ScamShield is a lightweight, high-performance rule-based scam and phishing detection system designed to help users instantly identify fraudulent communications across SMS, email, messaging platforms, and suspicious web links.

Detection Architecture

  • Pattern-Matching Rules: Natural Language Regex filters for urgent payment requests, OTP theft, lottery claims, bank verification fraud, and job scams.
  • Heuristic URL Analyzer: Evaluates IP-address domain hosting, shorteners, HTTP usage, and brand spoofing in URLs.
  • Weighted Scoring Matrix: Aggregates risk points up to a capped score of 100 with clear categorical risk tagging (Low, Medium, High, Critical).
  • SQLite Persistence: Stores scan telemetry and historical detection reports securely.

Technology Stack

Python 3 Flask Framework SQLite3 HTML5 & CSS3 Vanilla JavaScript unittest Framework

Disclaimer & Security Principles

This tool performs heuristic assessment for risk evaluation and does not guarantee 100% scam detection. It operates locally, does not store passwords or credentials, and never executes or visits submitted links.
